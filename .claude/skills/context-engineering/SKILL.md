# context-engineering

Authoritative state files (keep small, keep current): RESEARCH_STATUS.md, ARCHITECTURE_STATUS.md,
docs/engineering/context-state.md, requirements-traceability.md.

Navigate: read the index (00-research-index / ARCHITECTURE_STATUS) → identify the one relevant doc →
read the relevant section. Do not re-explain the whole project to yourself each task. Do not re-read
research authored this session unless the source changed, a requirement changed, a contradiction
appeared, or prior evidence was incomplete.

When context is large, STOP and update context-state.md (phase, objective, done, locked decisions,
open questions, changed files, tests run, key results, next action), then continue from it.
